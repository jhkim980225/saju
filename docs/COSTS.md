## 2. AI 호출 비용 (변동비)

| 기능 | 모델 | 언제 호출 | 건당 토큰(추정) | 건당 비용(추정) |
|---|---|---|---|---|
| AI 상담 | Haiku | 질문 1번마다 | 입력 6천 · 출력 1천 | 약 2원 |
| AI 꿈풀이 | Haiku | 풀이 1번마다 | 입력 4천 · 출력 1.5천 | 약 2원 |
| 사주분석서 다듬기 (A4 20쪽) | Haiku | 리포트당 **처음 한 번** (약 7덩어리) | 입력 4.5만 · 출력 5만 | 약 40원 |
| 신년운세·궁합·연애·재물직업 다듬기 | Haiku | 리포트당 처음 한 번 | 분석서의 절반 안팎 | 약 20원 |
| 택일 상세 | Haiku | 결과당 처음 한 번 | 입력 1만 · 출력 1만 | 약 10원 |
| 타로 이야기 | **Sonnet** | 유료 리딩당 한 번 | 입력 4천 · 출력 2천 | 약 45원 |

- 리포트·택일·타로 결과는 한 번 만든 뒤 저장해 두기 때문에, 같은 사람이 다시 열어도 AI 비용이 다시 나가지 않습니다.
- 무료 기능(오늘의 운세, 사주 풀이, 사주 요약, 띠·별자리 운세 등)은 규칙 기반 계산이라 **AI 비용이 0원**입니다.
- 시스템 프롬프트에 `cache_control` 을 걸어 두었습니다. 다만 프롬프트가 모델의 최소 캐시 길이보다 짧으면 캐시가 적용되지 않으므로, 위 추정에는 캐시 할인을 넣지 않았습니다.

### 실패했을 때

| 상황 | 동작 | 사용자 질문권 |
|---|---|---|
| `ANTHROPIC_API_KEY` 없음 | 모든 기능이 규칙 기반으로 동작 | 차감하지 않음 |
| 상담·꿈풀이 AI 호출 실패 | 규칙 기반 답변으로 대신 응답 | 먼저 차감한 1회를 **돌려줌** |
| 리포트 다듬기 실패 | 실패한 덩어리만 규칙 기반 초안을 그대로 씀 | 해당 없음 (리포트는 이미 결제됨) |
| 타로 이야기 실패 | 규칙 기반 문단을 씀 | 해당 없음 |

## 6. 비용이 갑자기 늘 수 있는 곳

- **Sonnet 타로 이야기**: 건당 비용이 Haiku 기능의 20배 이상입니다. 무료 스프레드에는 호출하지 않으므로, 이 조건을 바꿀 때는 비용을 다시 계산해야 합니다.
- **리포트 동시 생성**: 서버 전체 동시 호출을 16개로 제한해 두었습니다(`REPORT_GLOBAL_CONCURRENCY`). Anthropic 요금 등급의 분당 출력 토큰 한도를 넘지 않게 하려는 장치입니다.
- **요청 수 제한**: Cloudflare Rate Limiting으로 IP당 API 60초 120회, 인증 경로 60초 10회로 막아 두었습니다(`wrangler.jsonc`).
- **Anthropic 선불 크레딧 잔액**: 잔액이 바닥나면 AI 호출이 실패하고 규칙 기반으로 바뀝니다. 서비스는 멈추지 않지만 유료 리포트의 문장 품질이 낮아지므로, 콘솔에서 자동 충전이나 잔액 알림을 켜 두는 편이 안전합니다.
