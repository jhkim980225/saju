# 타로 카드 그림 — 출처와 변환

## 앞면 78장

- **원본**: 1909년 웨이트-스미스 덱 원판(그림 패멀라 콜먼 스미스, 1878~1951). 위키미디어 공용의 스캔본을 쓴다.
  - 메이저: `File:RWS Tarot NN Name.jpg` (예: `RWS Tarot 00 Fool.jpg`, 8번 Strength · 11번 Justice — 웨이트 순서)
  - 마이너: `File:Wands01.jpg` ~ `Wands14.jpg`, `Cups…`, `Swords…`, `Pents…` (11 페이지 · 12 나이트 · 13 퀸 · 14 킹)
- **저작권**: 공개 저작물. 그린 사람이 1951년에 사망해 한국(당시 사후 50년, 2001년 만료)·미국·유럽 모두 보호 기간이 끝났다.
  - 1971년 이후 미국 U.S. Games 가 낸 **다시 칠한 판**은 쓰지 않는다. 원판 스캔만 쓴다.
  - 'Rider-Waite' 는 U.S. Games 의 상표라 화면·문서에 쓰지 않는다. '웨이트-스미스' 로 적는다.
- **변환** (sharp): 가장자리 0.8%(좌우)·0.5%(위아래) 잘라 냄 → 484×836(11:19) 으로 맞춤 → 둥근 모서리(반경 16px) 바깥을 카드 여백색 `#ece2d5` 로 채움 → `blur(0.6)` 로 종이 잡티를 줄인 뒤 webp 품질 72. 바보(major-00) 스캔은 왼쪽에 스캔 바탕이 30px 더 있어 더 잘라 낸다. 78장 합계 약 4.3MB.
- 화면 비율은 `TarotCard.tsx` 의 `aspect-[11/19]` 이다. 켈틱 크로스의 2번(가로) 카드는 `scale-[0.7]` 로 옆 칸을 넘지 않게 한다.
