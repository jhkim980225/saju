# 제품 요구사항 (PRD) — 달빛사주(月光四柱)

> 마케팅·광고팀(`research/01`, `research/03`)과 홍보·브랜딩팀(`research/02`, `research/04`)의 기존 사주 서비스 분석을 바탕으로 팀장이 확정한 제품 결정입니다.

## 1. 포지셔닝
- **"맞히는 사주 말고, 읽히는 사주"** — 정밀 만세력 계산(전문 도구 수준) + 쉬운 해석(엔터테인먼트 앱 수준)을 한 서비스에. 리서치상 둘을 합친 서비스가 거의 없음(최대 차별화 기회).
- 디자인: **"먹과 여백"** — 무채색 UI, 색은 오행 데이터에만. 국내에 없는 절제된 동양 미니멀(Co-Star 류).
- 브랜드 보이스: "다정한 해석가" — 해요체, 단정 대신 경향, 근거 제시, 행동 제안, 공포 조장 금지.

## 3. 수익 모델 (마케팅팀 권장안 채택)
- **범용 코인 없음** — 리포트는 원화 단건 판매, AI 상담만 "질문권"(유효기간 없음, 유상/무상 분리 원장).
- 상품 카탈로그(`apps/api/src/modules/commerce/catalog.ts`):

| ID | 상품 | 가격 |
|---|---|---|
| `report_saju_mini` | 첫 사주 미니 리포트(재물·연애·직업 공개, 계정당 1회) | 990원 |
| `report_saju_lifetime` | 평생 사주분석서(A4 20쪽, PDF 저장) + 질문권 3 | 9,900원 (정가 19,800) |
| `report_newyear_2027` | 2027 신년운세 (12/31까지 얼리버드) | 5,900원 → 7,900원 |
| `report_compat` | 사주 궁합 리포트 | 5,900원 |
| `bundle_newyear_2027` | 평생 + 신년 + 궁합 1회권 + 질문권 10 | 16,900원 |
| `chat_pack_10` / `chat_pack_30` | AI 상담 질문권 | 3,900원 / 9,900원 |
| `tarot_question_3` / `tarot_love_5` | 타로 깊은 풀이(리딩 1건, 질문권 1회 포함) | 990원 / 2,900원 |

- 타로 '전문가' 표기: 가공 인물·경력 주장 없이 "1909년 웨이트-스미스 덱의 전통 해석 · 달빛사주 콘텐츠팀 작성"으로 표기한다(표시광고법, `research/05` §6). 실제 자문가를 영입하면 감수 범위만 실명으로 표기.
- 타로 카드 그림은 생성형 AI(Higgsfield, 최저가 모델)로 만든 뒤 78장 전수 검수했고, 앱 안 '달빛사주 타로는 이렇게 읽어요'에 그 사실을 밝힌다.

- 결제: 웹 1순위 토스페이먼츠, 2순위 포트원 V2(KCP/나이스). KG이니시스·네이버페이는 운세 업종 입점 불가. 앱은 IAP 필수(Apple 소규모 사업자 프로그램 15%), 구매 전 로그인 필수, 앱 내 웹 결제 유도 금지.
- 광고: **무료 결과 하단 + 홈(오늘) 인피드만**. 입력·결제·유료 리포트·AI 상담 화면 금지, 프리미엄 사용자 제외. 앱 리워드 광고 하루 3회.

## 4. UX 원칙 (홍보팀 권장안 채택)
- 결과를 먼저, 가입은 나중에(저장·재방문·결제 시점). 결제 후 읽던 섹션으로 복귀.
- 잠금은 **실제 첫 문단 공개 + 페이드 + 유료 목차 공개** (가짜 블러 텍스트 금지).
- 보정 내역(−32분 등)과 점수 근거("오늘 나와 만나는 기운")를 숨기지 않는다.
- 하단 탭: 오늘 · 내 사주 · 궁합 · 물어보기 · 마이. 다크 모드·글자 크기 설정.
- 데스크톱(1024px↑): 하단 탭 대신 상단 내비(＋만세력·이용권), 결과는 왼쪽 사주표·목차 고정 + 오른쪽 풀이의 2단, 오늘·궁합·신년운세·마이도 2단, 시트는 가운데 대화상자. 모바일 화면은 그대로.
- 문구: `apps/web/src/i18n/ko.json`(홍보팀 카피 415개)을 그대로 사용.
