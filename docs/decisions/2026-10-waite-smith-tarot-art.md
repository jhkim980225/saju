# 타로 카드 그림을 수묵 AI 그림에서 1909년 웨이트-스미스 원판으로 바꾼다

- 날짜: 2026-10-21
- 상태: 채택
- 관련 커밋:
  - `3fe8bb9` 타로 카드 그림을 1909년 웨이트-스미스 원판으로 교체: 수묵 AI 그림이 너무 동양풍이라는 의견
- 관련 문서: [TAROT_ART.md](../TAROT_ART.md), [PRD.md](../PRD.md) §3·§5, [features/tarot.md](../features/tarot.md)

## 맥락

2026-10-13 부터 10-15 까지 타로 카드 앞면 78장은 생성형 AI(Higgsfield)로 만든 수묵화였다. 이 그림이 "너무 동양풍"이라는 의견이 나왔다. 카드 뜻과 그림 설명(`imagery`) 글은 처음부터 1909년 원판 장면을 기준으로 쓰여 있었다.

## 결정

- 앞면 78장은 위키미디어 공용에 있는 1909년 웨이트-스미스 덱 원판 스캔(그림 패멀라 콜먼 스미스)을 쓴다. 484×836(11:19) webp 로 변환한다.
- 1971년 이후 U.S. Games 가 다시 칠한 판은 쓰지 않고 원판 스캔만 쓴다.
- 'Rider-Waite' 는 U.S. Games 의 상표라 화면과 문서에 쓰지 않고 '웨이트-스미스'로 적는다.
- 뒷면은 남색 바탕, 금빛 테두리, 초승달로 된 달달사주 디자인을 새로 그린다.
- 카드 비율을 2:3 에서 원판 비율 11:19 로 바꾼다.

## 근거

- 교체의 직접적인 이유는 "너무 동양풍"이라는 의견이다(`3fe8bb9`). 의견을 낸 사람과 경로는 기록에 없다. TODO: 확인 필요.
- 원판은 공개 저작물이다. 그린 사람이 1951년에 사망해 한국, 미국, 유럽 모두 보호 기간이 끝났다(TAROT_ART.md).
- 카드 뜻과 그림 설명 글이 원판 기준이라 글을 고치지 않고 그림만 바꿀 수 있었다.

## 결과와 영향

얻은 것:
- 화면의 그림과 카드 설명 글이 같은 원판을 가리킨다.
- 그림 사용권을 따로 확보할 필요가 없다.

감수한 것:
- 서비스 고유의 카드 앞면 그림이 없어졌다. 달달사주 디자인은 뒷면에만 남는다.
- 카드 비율이 바뀌어 화면 배치를 다시 맞췄다. 켈틱 크로스의 가로 카드 축소 비율을 0.8 에서 0.7 로 줄이고 섞기 화면의 카드 묶음 비율을 고쳤다.
- 78장 합계 약 4.3MB 의 이미지 파일을 웹 빌드에 넣는다.
- 안내 문구의 'AI 수묵 카드' 설명을 원판 출처 설명으로 바꿨다.
