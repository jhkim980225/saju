# 플러스 구독과 질문권 100회를 빼고 일회성 상품만 판다

- 날짜: 2026-10-15
- 상태: 채택
- 관련 커밋:
  - `79c5413` 상품: 플러스 구독·질문권 100회 제외(일회성 판매만)
  - `f70f2ff` 주제별 리포트: 연애·결혼운, 재물·직업운(각 4,900원, 일회성)
- 관련 문서: [PRD.md](../PRD.md) §2·§3, [FEATURES.md](../FEATURES.md) §22 11번, [PAYMENTS.md](../PAYMENTS.md) §3.1, [features/payments.md](../features/payments.md), [features/reports.md](../features/reports.md), [features/ask.md](../features/ask.md)

## 맥락

첫 커밋의 PRD §2 는 2차 기능으로 "구독(플러스), 연애·재물 심층 리포트, 질문권 100회"를 두고, 카탈로그에는 출시 예정(`comingSoon`) 상품으로 넣어 두었다. 이용권 화면에도 '플러스 구독' 묶음이 있었다. PRD §3 의 수익 모델은 이미 범용 코인 없이 리포트를 원화 단건으로 팔고 AI 상담만 질문권으로 파는 구조였다.

## 결정

- 플러스 구독과 질문권 100회 팩을 카탈로그에서 뺀다. 사용자 결정(2026-10-15)이다.
- 상품 시드는 카탈로그에 없는 기존 상품을 판매 중지(`active=false`)한다. 이용권 화면의 '플러스 구독' 묶음도 뺀다.
- 같은 날 2차 목록의 연애·재물 심층 리포트는 각 4,900원의 일회성 리포트로 만들었다(`f70f2ff`).
- 구독 처리 코드(`premiumUntil` 등)는 지우지 않고 쓰지 않는 채로 남긴다.

## 결과와 영향

얻은 것:
- 상품은 리포트·풀이 단건, 질문권 10회·30회 팩, 신년 패키지처럼 한 번 결제로 끝나는 것만 남았다. 정기결제, 갱신, 해지, 기간 연장을 처리할 필요가 없다.
- 웹 결제를 결제창마다 가격이 고정된 그로블로 옮길 때 구독 상품을 맞출 필요가 없었다([2026-10-groble-web-payments.md](./2026-10-groble-web-payments.md)).

- 플러스 판정 코드(`isPremium`, `premiumUntil`)가 화면 곳곳에 남아 있지만 구독 상품이 없어 누구도 플러스가 되지 않는다(FEATURES.md §22 11번). PRD §3 의 광고 규칙 "프리미엄 사용자 제외"도 해당하는 사용자가 없다.
