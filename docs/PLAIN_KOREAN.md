# 문체 기준 — 사주를 처음 접하는 성인도 쉽게 이해하는 전문 서비스

2026-10-16 개정. 이전 기준은 "사주를 전혀 모르는 사람 기준, 본문에 용어 금지"였고, 이 문서가 그것을 대체한다.

- 목표: '어린이도 이해할 수 있는 사주 서비스'가 아니라, **'사주를 처음 접하는 성인도 쉽게 이해할 수 있는 전문적인 서비스'**를 만든다.
- 기준 예시: `/basics`(사주 기초) 화면, `apps/web/src/lib/sajuBasics.ts`의 용어 설명.

## 1. 읽는 사람

- 성인이다. 사주를 처음 접했을 수 있지만, 설명을 들으면 개념을 이해할 수 있다.
- 쉽게 설명하는 것과 어린아이에게 설명하는 것은 다르다.

## 2. 문체

1. **친근하지만 차분하고 전문적인 설명체로 쓴다.**
2. **존댓말은 '~해요'를 기본으로 하되, 문장 성격에 따라 '~입니다/~합니다'를 쓴다.**
   - 개념 정의, 명리학적 근거, 서비스 안내 문장은 '~입니다/~합니다'가 자연스럽다.
   - 모든 문장을 기계적으로 '~해요'로 끝내지 않는다.
   - 한 문단 안에서 두 어미가 오가도 읽기에 어색하지 않게 한다.
3. **해석은 확정된 사실이 아니라 명리학적 해석으로 쓴다.**
   - '~하는 경향이 있다고 봐요', '~로 해석해요', '~기 쉽습니다', '~할 수 있어요'처럼 쓴다.
   - '반드시', '무조건', '~하게 돼요'처럼 단정하지 않는다.
4. **유아적인 표현을 쓰지 않는다.** 문맥에 맞는 전문 표현으로 바꾼다.
   - '눌러요' → '극해요 / 제어해요'
   - '숨어 있어요' → '담겨 있어요 / 내재해 있어요'
   - '힘을 내요' → '힘을 얻어요 / 강해져요'
   - '쑥쑥', '반짝', '콕', '척척' 같은 의태어도 쓰지 않는다.
5. **과도한 의인화, 비유, 감성 표현을 쓰지 않는다.**
   - 예: 순풍에 돛 단 듯, 씨앗, 꽃을 피우다, 날개를 달다, 빛을 보다, 큰 나무 같은 사람, 오늘의 주인공.
   - 사람을 자연물에 빗대지 않는다. 성향을 직접 말한다.
6. **AI가 쓴 듯한 반복 패턴을 줄인다.**
   - 같은 어미('~해 보세요', '~하면 좋아요')를 연달아 쓰지 않는다.
   - 문단마다 같은 구조('장점 → 다만 → 해 보세요')를 되풀이하지 않는다.
7. **간결하게 쓴다.**
   - 같은 내용을 두 번 말하지 않는다. 머리말·요약·본문이 같은 문장을 반복하지 않는다.
   - 의미가 정확한 문장은 불필요하게 고치지 않는다.
8. **이름으로 부른다.**
   - '당신'이나 '너'로 부르지 않는다. 이름이 있으면 '서윤님'으로 부르고, 없으면 주어를 뺀다.
   - 조사는 `josa()`로 맞춘다.
9. **겁주지 않는다.**
   - 조심할 점은 구체적인 상황과 대처법을 함께 쓴다.
   - 이혼·사고·질병을 단정하지 않는다. 의료·법률·투자는 단정하지 않는다.
10. **화면의 숫자와 글이 맞아야 한다.** 차트·점수와 본문의 수치를 맞춘다.

예시

| 나쁨 | 좋음 |
|---|---|
| 오늘은 순풍에 돛 단 듯 가벼운 날 | 계획한 일이 순조롭게 진행되기 쉬운 날입니다 |
| 앞의 기운이 뒤의 기운을 눌러요 | 앞의 오행이 뒤의 오행을 극(剋)하여 제어하는 관계로, 서로 견제하며 균형을 이룹니다 |
| 아래 글자 속에 숨어 있는 글자 | 지지 안에 담긴 천간(지장간) |
| 나쁜 운이라는 뜻은 아니고 | 반드시 나쁜 결과를 의미하지는 않아요 |
| 마음먹은 만큼 채워지지 않기 쉽다고 봐요 | 기대와 현실 사이에 차이가 생길 수 있다고 해석해요 |

## 3. 사주 용어

1. **정식 명리학 용어를 유지한다.**
   - 대상: 천간, 지지, 일간, 일주, 오행, 음양, 십성(비견·겁재·식신·상관·편재·정재·편관·정관·편인·정인), 용신·희신·기신, 대운·세운, 신강·신약, 12운성, 신살, 합·충 등.
2. **한 화면에서 처음 나오는 전문 용어에는 뜻을 붙인다.** 두 번째부터는 용어만 쓴다.
   - 예: "일간(태어난 날의 천간으로, 나 자신을 나타내는 글자)"
   - 예: "편재(일간이 극하는 오행 가운데 음양이 같은 것으로, 유동적인 재물을 뜻해요)"
3. **오행은 정식 이름(목·화·토·금·수)을 쓴다.**
   - 이해를 돕는 자리에서는 '목(나무)'처럼 쉬운 이름을 함께 쓸 수 있다.
   - 한 화면 안에서는 표기를 일관되게 한다.
   - 차트 범례처럼 이미 '나무·불·흙·쇠·물'로 된 UI는 그대로 둘 수 있다.
4. **한자는 본문에서 꼭 필요한 정의 자리에만 괄호로 한 번 쓴다.** 예: 용신(用神). 사주표, 전문가 보기, 근거(basis)에서는 자유롭게 쓴다.
5. **쉽게 만들려고 개념의 정확성을 훼손하지 않는다.**

## 4. 전통 명리학과 달빛사주 자체 기준을 구분한다

**서비스가 만든 점수·등급·지표는 "달빛사주 기준" 또는 "서비스 자체 지표"라고 밝힌다.** 화면에서 한 번이면 된다. 대상은 다음과 같다.
- 오늘 총운 점수, 분야별 점수
- 운세 등급('좋은 날', '조심할 해' 등)
- 궁합 점수와 등급
- 신강·신약 0~100점과 단계 이름
- 오행 개수 집계
- 용신 계산 방식
- 대운 시작 나이 계산
- 택일 등급

**자주 틀리는 개념 — 정확한 설명** (사주 기초 화면과 같은 내용)
- **천간·지지**: 하늘과 땅의 기운을 상징한다. '천간 = 겉 성향, 지지 = 속마음'으로만 단정하지 않고, 다른 글자와의 관계를 함께 본다고 쓴다.
- **신강·신약**: 보편적인 0~100점 기준은 없다. 점수는 달빛사주 지표다. 강약 자체에 좋고 나쁨은 없다.
- **용신**: 억부·조후·격국 등 여러 방법이 있고, 학파에 따라 결과가 다르다.
  - 달빛사주는 억부 중심의 간이 계산이다(조후·격국 미반영). 강약이 균형에 가까우면 가장 약한 오행으로 정한다.
  - '부족한 오행을 채우는 기운'으로만 설명하지 않는다.
- **희신·기신**: 희신은 용신을 생하는 오행, 기신은 용신을 극하는 오행이다. 기신이 강한 시기가 반드시 나쁜 것은 아니다.
- **대운**: 10년 단위다. 시작 나이는 사람마다 다르다(성별·태어난 해의 음양·출생일과 절기 사이의 날수). 출생 직후부터 시작한다고 쓰지 않는다. 달빛사주는 날수를 3으로 나눠 계산한다.
- **세운·일진**: 그해·그날의 간지와 사주의 관계로 해석한다.
- **오행 분포**: 여덟 글자를 단순히 센 값이다(지장간·계절 미반영).
- **지지의 십성**: 지장간 본기 기준이다.
- **십성의 정·편**: 일간과 음양이 같으면 비견·식신·편재·편관·편인이고, 다르면 겁재·상관·정재·정관·정인이다.
- **신살**: 보조 요소다. 신살 하나로 길흉을 판단하지 않는다. '살'이 붙었다고 나쁜 일이 생긴다고 쓰지 않는다.
- **12운성**: 단계 이름이 곧 길흉이 아니다.
- **공망**: 일주 기준이다.
- **합·충**: 합은 조화와 결합, 충은 대립과 변화다. 충을 곧 사고나 이별로 단정하지 않는다.

## 5. 화면 구조

- 기존 구조와 기능은 유지한다: '한눈에 보는' 요약 카드, '사주로 보면' 접힘(근거를 더 보고 싶은 사람용), 전문가 보기, 잠금 섹션.
- 제목은 짧고 직관적으로 쓴다(예: '사주는 여덟 글자로 이루어져 있어요', '타고난 성격', '재물운').

## 6. 검사

- `apps/api/test/plain-tone.test.ts`는 콘텐츠 파일을 훑는다.
  - `plainGuard.ts`의 FIGURATIVE(비유·관용구) 목록과 CHILDISH(유아적 표현) 목록을 쓴다.
  - 목록은 대표적인 것만 담는다. 나머지는 사람 눈 검사로 고친다.
- `plain-*.test.ts`는 여러 사주로 화면 글을 모아 검사한다.
  - 검사 항목: 본문 한자, '당신', 어색한 이음새(조사·`undefined`·이중 공백), 같은 문장 반복.
  - 용어 금지 검사는 이번 개정에서 뺐다.
- AI 다듬기가 초안에 없던 용어·한자·비유를 새로 들이면, 그 섹션은 규칙 기반 초안을 쓴다(`introducesJargon`, `introducesFigurative`).
- 사람 눈 검사: 고친 화면의 실제 글을 뽑아 '사주를 처음 접하는 성인'으로서 처음부터 끝까지 읽는다. 스크린샷도 확인한다.
