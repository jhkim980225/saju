# 사주 계산 엔진 (`@saju/core`) — 계산 방법과 검증

## 1. 입력
```ts
calculateSaju({
  calendar: 'solar' | 'lunar', year, month, day, isLeapMonth?,
  hour?: 0~23 | null,   // null = 태어난 시간 모름 → 시주 없이 6글자
  minute?, gender: 'male' | 'female',
  timeZone?: 'Asia/Seoul',         // IANA — 해외 출생 지원
  longitude?: 126.978,             // 출생지 경도 (기본 서울)
  timeCorrection?: 'lmt' | 'trueSolar' | 'clock',   // 기본 lmt(경도 보정)
  ziHourRule?: 'nextDay' | 'midnight',              // 기본 nextDay(23시부터 다음 날)
})
```

## 2. 계산 단계

| 단계 | 방법 |
|---|---|
| 음력 → 양력 | `korean-lunar-calendar` (한국천문연구원 KASI 데이터, 1000~2050년). 한국 음력은 중국 음력과 일부 해에 다르므로 한국 데이터 사용. 없는 윤달·날짜는 오류 |
| 출생 시각 → UTC | IANA 시간대 DB(Intl)로 변환 → **한국의 1954~1961 UTC+8:30, 서머타임(1948~51, 1955~60, 1987~88)** 자동 반영 |
| 년주 | **입춘 시각** 기준. 입춘 전 출생은 전년도 간지 |
| 월주 | **12절(節)** 시각 기준(입춘·경칩·청명·입하·망종·소서·입추·백로·한로·입동·대설·소한). 월간은 오호둔(甲己년 丙寅월 …) |
| 절기 시각 | `lunar-javascript`(寿星天文历 알고리즘)의 북경시(UTC+8) 결과를 UTC 로 환산. KASI 발표 KST 와 분 단위 일치 검증 |
| 일주 | 율리우스 적일(JDN) — `(JDN + 49) mod 60` (2000-01-01 = 戊午) |
| 시간 보정 | `lmt`: 지방평균태양시 = UTC + 경도×4분 (서울 약 −32분) / `trueSolar`: + 균시차 / `clock`: 보정 없음 |
| 시주 | 보정 시각으로 시지(23:00 子 …), 시간은 오서둔(甲己일 甲子시 …) |
| 자시 처리 | `nextDay`: 23시부터 다음 날 일주(통자시) / `midnight`: 야자시 — 일주는 당일, 시주 천간은 다음 날 기준 |
| 시간 모름 | 정오 기준으로 년·월 판정, 생일 당일 절입이 있으면 경고 |

| 항목 | 방법 |
|---|---|
| 십신 | 일간 대비 오행 생극 + 음양 동이. 지지는 본기(정기) 지장간 기준 |
| 지장간 | 월률분야(여기·중기·정기, 일수) |
| 12운성 | 양간 순행·음간 역행, 장생지 표 |
| 오행 분포 | 글자 수 + 지장간 비율 가중(월지 1.5배) 점수 |
| 신강·신약 | 년간10·월간10·시간10·년지10·월지30·일지15·시지15 가중치 중 일간을 돕는(비겁·인성) 비율. 득령·득지·득세 표시 |
| 용신 | **간이 억부용신**(조후·통관 미반영 — 화면에 참고용으로 표기). 신강: 인성 과다면 재성, 비겁 과다면 관성/식상 / 신약: 재성 과다면 비겁, 그 외 인성 / 중화: 가장 약한 오행 |
| 합충 | 천간합·천간충, 육합·반합(왕지 포함)·삼합·방합, 충·형(삼형·자묘·자형)·파·해·원진 |
| 신살 | 천을·문창·학당·천덕·월덕귀인, 도화·역마·화개(년지/일지 삼합 기준), 홍염, 양인, 괴강, 백호, 현침, 귀문관, 원진, 공망(일주 순중) |

| 세운·월운·일진 | 연간지(입춘 기준), 월운(절기 구간), 일진(JDN) |
| 운 평가 | 운 간지의 용신/희신/기신 적합도 + 12운성 에너지 + 원국과의 합충 + 신살 하이라이트 → 총운·재물·애정·직장·건강·학업 점수(10~98). 같은 입력은 항상 같은 결과(결정적 변동치) |
| 궁합 | 일간 관계(합·생·극·충) + 일지(배우자궁) 관계 + 띠 관계 + 오행 보완 + 용신 보완 + 배우자성(남: 재성, 여: 관성) → 점수와 근거 문장 |

## 5. 한계와 정책 (사용자 고지 필요)
- 용신은 억부법 간이 판단입니다. 조후용신·격국은 반영하지 않습니다.
- 대운수 반올림·자시 처리·시간 보정 방식은 유파마다 다릅니다 → 고급 설정에서 사용자가 선택 가능.
- 지원 범위: 양력 1900~2100년, 음력 입력 1000~2050년(실사용 1900~2050).

## 6. 택일(擇日) — `src/taekil.ts`

목적에 맞춰 좋은 날을 고른다. 하루 점수 = 기준 50 + **통서(通書) 요소**(누구에게나 같은 그날의 성질) + **본명(本命) 요소**(그날 일진과 내 사주). 같은 입력은 항상 같은 결과이고, 엔진은 점수·등급·요인 코드(라벨·근거 글자·가감)만 내고 문장은 API(`apps/api/src/modules/taekil/content.ts`)가 만든다.

```ts
selectTaekilDays(chart, 'move' | 'contract' | 'exam' | 'wedding' | 'opening' | 'travel', dates, { partner? })
// dates: taekilDateRange(from, to) (최대 92일) 또는 후보 날짜(API 는 2~10개). partner 는 결혼에서만 쓴다
// → { days: TaekilDay[](날짜순), ranking, top(≤3), counts }
```

| 항목 | 정책 |
|---|---|
| 등급 | 대길 ≥68 · 길 ≥58 · 보통 ≥44 · 주의 ≥34 · 피함. **탈락 사유**(월파·사리/사절·일지 충)가 있으면 점수와 무관하게 피함 |
| 등급 경계 | 원국 40개 × 92일 × 6목적 분포에서 대길 3~6%, 길 15~23%, 피함 약 20%(탈락 18%)가 되도록 정했다 |
| 순위 | 탈락 여부 → 점수 → 흉한 요인 합이 작은 날 → 이른 날. Top 3 는 '피함'을 뺀 상위 3일(없으면 빈 목록) |
| 날짜 기준 | 모든 날짜·절기는 KST. 음력은 KASI(한국) 데이터라 중국 음력과 하루 다른 달도 한국 기준 |

### 6.2 건제12신의 목적별 가중치

직마다 무엇에 좋고 나쁜지는 문헌마다 어긋난다. 통속 구결 「建滿平收黑，除危定執黃，成開皆可用，閉破不相當」은 출처가 없는 민간 구결이고, 協紀辨方書가 인용한 選擇宗鏡은 「平成開危最吉，定除次吉，破大凶」으로 평(平)을 오히려 길하게 본다. 하나를 골라 쓰지 않고, **協紀辨方書의 일별 宜忌 체계를 구현한 lunar-javascript 에서 2000-01-01~2029-12-31(10,958일)의 宜·忌 표기를 직별로 집계**했다.

- net% = (그 직에서 용사가 宜로 적힌 날의 비율 − 忌(또는 諸事不宜)로 적힌 날의 비율) × 100
- 가중치 = round(net ÷ 6), −10~+7로 자름. 용사: 이사 移徙·入宅 / 계약 立券·交易 / 면접·시험 入學·赴任 / 결혼 嫁娶 / 개업 開市 / 여행 出行

| 목적 | 건 | 제 | 만 | 평 | 정 | 집 | 파 | 위 | 성 | 수 | 개 | 폐 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 이사 | −5 | +4 | −5 | −5 | **+6** | −1 | −10 | +5 | −1 | −4 | −3 | −3 |
| 계약 | +2 | +4 | **+7** | −1 | +5 | −4 | −7 | +5 | +6 | −1 | +4 | +3 |
| 면접·시험 | −2 | +1 | 0 | −3 | +1 | 0 | −7 | +1 | −1 | −2 | 0 | 0 |
| 결혼 | −3 | +2 | −1 | −5 | +3 | −1 | −10 | +4 | −6 | −3 | **+6** | −3 |
| 개업 | −2 | 0 | +5 | −3 | 0 | −10 | −10 | +2 | **+7** | −9 | +2 | −5 |
| 여행·출발 | +5 | +4 | +3 | −2 | +6 | +3 | −8 | **+7** | +1 | −2 | +6 | +1 |

원자료 net% 는 `OFFICER_NET` 에 있다. 면접·시험(入學·赴任)은 통서에 宜로 적히는 날 자체가 드물어(13% 이하) 직의 영향이 작고, 대신 문창귀인·관성·인성(§6.3)이 순위를 가른다. 破는 모든 용사에서 宜가 0% 라 따로 탈락 사유로 둔다.

### 6.3 본명 요소 — 그날 일진과 내 사주

택일의 첫 원칙은 '본명을 해치지 않는 날'이다. 서열은 운세 평가(`fortune.ts`)와 같게(충 > 형 > 원진 > 파·해, 일지 > 년지) 두고, 관행대로 **일지 충만 탈락 사유**로 둔다. 십신·신살 요소는 통서보다 문헌 근거가 약해 작게 둔다.

| 요소 | 규칙 | 가감 |
|---|---|---|
| 일지(나·배우자 자리) | 충(탈락) · 형 · 자형 · 원진 · 파 · 해 / 육합 · 삼합(반합) | −16 · −6 · −3 · −5 · −3 · −3 / +7 · +4 |
| 띠(년지, 본명) | 충 · 형 · 자형 · 원진 · 파 · 해 / 육합 · 삼합 | −10 · −4 · −2 · −3 · −2 · −2 / +4 · +3 |
| 일간 | 천간합 / 천간충, 천간충+일지충(천극지충)이면 추가 | +4 / −5, −6 |
| 천을귀인 | 일진 지지가 일간의 천을귀인 | +7 |
| 공망 | 일진 지지가 일주 순중 공망 | −4 |
| 용신 | 일진 천간 오행이 용신·희신·기신 +4·+2·−4, 지지 본기 +3·+1·−3 (간이 억부용신, §5) | 합산 |
| 목적별 십신 | 면접·시험: 관성·인성 +3, 상관 −3 / 계약: 정재·정인 +3, 겁재 −4 / 개업: 식신·재성 +3, 겁재 −4 / 결혼: 남 정재 +4·편재 +2·겁재 −3, 여 정관 +4·편관 +2·상관 −3 / 이사: 정인 +2 | |
| 목적별 신살 | 면접·시험 문창귀인 +5 / 역마(년지·일지 삼합 기준) 이사 +3·여행 +5 | |
| 결혼 상대(선택) | 상대 일지 충 −12 · 형 −4 · 원진 −3 · 육합 +4, 상대 띠 충 −6 · 육합 +2, 상대 천을귀인 +3 | |
