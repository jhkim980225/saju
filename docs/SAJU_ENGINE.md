# 사주 계산 엔진 (`@saju/core`) — 계산 방법과 검증

## 1. 입력
```ts
calculateSaju({
  calendar: 'solar' | 'lunar', year, month, day, isLeapMonth?,
  hour?: 0~23 | null,   // null = 태어난 시간 모름 → 시주 없이 6글자
  minute?, gender: 'male' | 'female',
  timeZone?: 'Asia/Seoul',         // IANA — 해외 출생 지원
  longitude?: 126.978,             // 출생지 경도 (기본 서울)
  timeCorrection?: 'lmt' | 'trueSolar' | 'clock',   // 기본 lmt(경도 보정)
  ziHourRule?: 'nextDay' | 'midnight',              // 기본 nextDay(23시부터 다음 날)
})
```

## 2. 계산 단계

| 단계 | 방법 |
|---|---|
| 음력 → 양력 | `korean-lunar-calendar` (한국천문연구원 KASI 데이터, 1000~2050년). 한국 음력은 중국 음력과 일부 해에 다르므로 한국 데이터 사용. 없는 윤달·날짜는 오류 |
| 출생 시각 → UTC | IANA 시간대 DB(Intl)로 변환 → **한국의 1954~1961 UTC+8:30, 서머타임(1948~51, 1955~60, 1987~88)** 자동 반영 |
| 년주 | **입춘 시각** 기준. 입춘 전 출생은 전년도 간지 |
| 월주 | **12절(節)** 시각 기준(입춘·경칩·청명·입하·망종·소서·입추·백로·한로·입동·대설·소한). 월간은 오호둔(甲己년 丙寅월 …) |
| 절기 시각 | `lunar-javascript`(寿星天文历 알고리즘)의 북경시(UTC+8) 결과를 UTC 로 환산. KASI 발표 KST 와 분 단위 일치 검증 |
| 일주 | 율리우스 적일(JDN) — `(JDN + 49) mod 60` (2000-01-01 = 戊午) |
| 시간 보정 | `lmt`: 지방평균태양시 = UTC + 경도×4분 (서울 약 −32분) / `trueSolar`: + 균시차 / `clock`: 보정 없음 |
| 시주 | 보정 시각으로 시지(23:00 子 …), 시간은 오서둔(甲己일 甲子시 …) |
| 자시 처리 | `nextDay`: 23시부터 다음 날 일주(통자시) / `midnight`: 야자시 — 일주는 당일, 시주 천간은 다음 날 기준 |
| 시간 모름 | 정오 기준으로 년·월 판정, 생일 당일 절입이 있으면 경고 |

## 3. 분석
| 항목 | 방법 |
|---|---|
| 십신 | 일간 대비 오행 생극 + 음양 동이. 지지는 본기(정기) 지장간 기준 |
| 지장간 | 월률분야(여기·중기·정기, 일수) |
| 12운성 | 양간 순행·음간 역행, 장생지 표 |
| 오행 분포 | 글자 수 + 지장간 비율 가중(월지 1.5배) 점수 |
| 신강·신약 | 년간10·월간10·시간10·년지10·월지30·일지15·시지15 가중치 중 일간을 돕는(비겁·인성) 비율. 득령·득지·득세 표시 |
| 용신 | **간이 억부용신**(조후·통관 미반영 — 화면에 참고용으로 표기). 신강: 인성 과다면 재성, 비겁 과다면 관성/식상 / 신약: 재성 과다면 비겁, 그 외 인성 / 중화: 가장 약한 오행 |
| 합충 | 천간합·천간충, 육합·반합(왕지 포함)·삼합·방합, 충·형(삼형·자묘·자형)·파·해·원진 |
| 신살 | 천을·문창·학당·천덕·월덕귀인, 도화·역마·화개(년지/일지 삼합 기준), 홍염, 양인, 괴강, 백호, 현침, 귀문관, 원진, 공망(일주 순중) |
| 대운 | 양남음녀 순행·음남양녀 역행, 출생~다음(이전) 절입 일수 ÷ 3 = 대운수(반올림, 1~10), 10개 |
| 세운·월운·일진 | 연간지(입춘 기준), 월운(절기 구간), 일진(JDN) |
| 운 평가 | 운 간지의 용신/희신/기신 적합도 + 12운성 에너지 + 원국과의 합충 + 신살 하이라이트 → 총운·재물·애정·직장·건강·학업 점수(10~98). 같은 입력은 항상 같은 결과(결정적 변동치) |
| 궁합 | 일간 관계(합·생·극·충) + 일지(배우자궁) 관계 + 띠 관계 + 오행 보완 + 용신 보완 + 배우자성(남: 재성, 여: 관성) → 점수와 근거 문장 |

## 4. 검증 (`npm test -w @saju/core`)
- **lunar-javascript 八字와 무작위 3,000건 교차 검증** — 년·월·일·시주 전부 일치 (고정 UTC+8, 보정 없음, 야자시 조건)
- KASI 절입 시각: 2024 입춘 17:27, 2025 입춘 23:10, 2000 입춘 21:40, 2024 경칩 11:22 (KST)
- 1988 서머타임(−92분), 1956 UTC+8:30(−2분), 서울 경도 보정(−32분)
- 음력: 1990-04-21 = 1990-05-15, 2023 윤2월, 없는 윤달 오류
- 통자시/야자시, 시간 모름(6글자·절입 경고), 대운 순행/역행·대운수, 24절기 목록

## 5. 한계와 정책 (사용자 고지 필요)
- 용신은 억부법 간이 판단입니다. 조후용신·격국은 반영하지 않습니다.
- 대운수 반올림·자시 처리·시간 보정 방식은 유파마다 다릅니다 → 고급 설정에서 사용자가 선택 가능.
- 지원 범위: 양력 1900~2100년, 음력 입력 1000~2050년(실사용 1900~2050).

## 6. 띠별 운세 · 별자리 운세 (`zodiac.ts` · `astro.ts`)

개인 원국 없이 "띠 하나" 또는 "태양 별자리 하나"로 보는 무료 공개 콘텐츠의 계산 방법입니다. 문장은 API 콘텐츠 계층(`apps/api/src/modules/zodiac/content/`)이 계산 결과로 풀을 고르고, 같은 풀 안의 변형은 (띠·별자리, 기간, 기간 시작일) 해시로 정하므로 **같은 입력은 항상 같은 결과**입니다(무작위 없음).

### 6.1 띠별 운세
| 항목 | 방법 |
|---|---|
| 띠 | 년지(年支). 사주와 같이 **입춘**을 해의 경계로 본다(포털의 "음력 평달 1월 1일 기준"과 다름 — 화면에 그대로 고지). 프로필의 띠도 입춘 기준 원국 년지 |
| 기간별 운 기둥 | 오늘·내일 = 그 날 일진(JDN), 이번 달 = 그 날 **정오(KST)**가 속한 절기 달의 월건(오호둔), 올해 = 정오가 속한 사주 연도의 세운(입춘~입춘). 절입일은 정오 기준(절입이 오후면 그날은 앞 달) |
| 지지 관계 | `branchBonds(띠, 운 지지)` — 육합(+3), 같은 삼합국의 두 글자(+2, 왕지가 없어도 포함), 같은 글자(+1)·자형(−1), 충(−3), 형(−2), 원진(−2), 해(−1), 파(−1). 대표 관계 우선순위: 충 > 육합 > 삼합 > 형 > 원진 > 같은 글자 > 해 > 파 |
| 오행 작용 | 운 천간 오행 → 띠 지지 오행: 생해 줌(+1) / 같음 / 띠가 생해 줌 / 띠가 극함 / 띠를 극함(−1) |
| 흐름(tone) | 합(육합·삼합)과 형충파해·원진이 함께면 `mixed`, 아니면 점수 ≥ 2 `good`, ≤ −2 `caution`, 그 사이 `calm` |
| 이번 주 | 월~일 7일 일진 각각의 지지 관계 점수(≥ 2 좋은 날, ≤ −2 살필 날)를 모아 흐름을 정하고, 그 주가 속한 월건과의 관계를 바탕으로 함께 보여 준다 |
| 년생별 | 기준 연도 7~90세의 같은 띠 출생 연도. 태어난 해 천간과 운 천간의 **천간합 → 천간충 → 십신**(태어난 해 천간을 나로 봄)으로 문장을 고르고, 나이대(~19·20~34·35~49·50~64·65~) 실천 한 줄을 붙인다. 이번 주는 7일 중 천간 관계 순위(합 > 정인 > 편인·정관·식신·정재 > 비견·편재 > 상관 > 겁재 > 편관 > 충)가 가장 높은 날 |
| 행운 포인트 | 육합·삼합이 있으면 그 합이 만드는 오행, 없으면 띠 오행을 생해 주는 오행의 색·방향·수 |

### 6.2 별자리 운세 — 간이 천문 계산(외부 의존성 없음)
| 천체 | 방법 | 검증·오차 |
|---|---|---|
| 태양 | Meeus 『Astronomical Algorithms』 25장 저정밀식(겉보기 황경) | 1950~2049 중기(춘분 0°·곡우 30° …, lunar-javascript·KASI 절기) 시각에서 최대 0.009° — 테스트 한계 0.05° |
| 달 | Meeus 47장 경도 주기항 상위 34개 + 섭동 3항 | Meeus 예제 47.a(133.1627°) 대비 0.0014°. KASI 음력 초하루 정오의 달·태양 이각이 ±8° 안(2000~2049, 600개월). 별자리를 옮기는 시각은 1시간 안팎 차이 가능 |
| 목성·토성 | JPL(Standish) 근사 케플러 궤도 요소(1800~2050)로 태양 중심 위치 → 지구 위치를 빼 지심 황경, 세차 1.397°/세기 | 목성 게자리 입궁 2025-06-10, 사자자리 2026-06-30, 처녀자리 2027-07-26 / 토성 양자리 2026-02-13 — 알려진 날짜와 하루 안팎 |

| 항목 | 방법 |
|---|---|
| 내 별자리 | 태양 별자리 날짜표(양 3/21~4/19 … 물고기 2/19~3/20, `@saju/shared` `starSignOfBirthday`). 1950~2049 모든 날 정오(KST)의 실제 태양 별자리와 **경계일 앞뒤 하루를 빼고 전부 일치**(테스트). 경계일은 `isCusp` 로 "옆 별자리일 수 있어요" 안내. 음력 프로필은 서버 원국 계산의 양력 날짜로 |
| 자리(하우스) | 홀사인 하우스(solar house): 천체가 지나는 별자리를 내 별자리부터 1번으로 센 순서 1~12. 각: 1 같은 별자리, 3·11 = 60°, 4·10 = 90°, 5·9 = 120°, 7 = 180°, 2·12 = 30°, 6·8 = 150° |
| 흐름 | 같은 별자리·60°·120° `good`, 30° `calm`, 150°·180° `mixed`, 90° `caution` |
| 오늘·내일 | 그 날 **정오(KST)** 달의 별자리. 그날 0~24시에 달이 별자리를 옮기면 그 시각(정시 반올림)도 안내 |
| 이번 주 | 월~일 매일 정오의 달 별자리. 120°·같은 별자리·60° 날을 좋은 날, 90°·180° 날을 살필 날로(같은 별자리에 머무는 날은 첫날만, 각 2개까지), 태양 자리를 바탕으로 |
| 이번 달 | 태양이 지금 머무는 별자리 기간(입궁~다음 입궁)과 다음 별자리로 옮기는 시각 |
| 올해 | 그 날의 목성(넓어지는 것)·토성(다지는 것) 자리, 연내 목성 이동 안내. 제목·흐름은 목성 기준 |

- 화면 고지: "재미와 참고용", "간이 천문 계산이라 달은 1시간, 행성은 며칠 안팎 차이" — 응답의 `basisNote`·`disclaimer`.
- 검증: `npm test -w @saju/core` (`test/zodiac.test.ts` — 손으로 확인한 일진·월건·세운, 지지 관계 표, 천문 계산), `npm test -w @saju/api` (`test/zodiac.test.ts` — API·결정성·금지 표현·생일 날짜표 대 천문 계산).
