# 02. 사주·운세 서비스 UI/UX 경쟁 분석 & 디자인 방향 권장안

- 작성: 홍보·브랜딩팀 리서치 (담당 범위: UI/UX, 문구는 `04-copywriting-guide.md`)
- 작성일: 2026-10-12
- 대상 독자: 개발 리드, 프론트엔드(웹 → Capacitor 앱 포팅), 디자이너
- 범위 밖: 기능 목록·가격 정책 비교(다른 팀원 담당). 이 문서에서는 화면 구성을 설명할 때 필요한 만큼만 언급합니다.

---

## 0. 요약 (TL;DR)

1. 시장의 비주얼은 크게 다섯 갈래입니다. ① **전통·권위형**(수묵화, 한지, 금색, 붓글씨: 포스텔러 신년 시즌, 청월당) ② **대시보드·진단형**(점수, 그래프, 게이지: 점신, 정통사주) ③ **캐릭터·세계관형**(다크 테마, 무속 캐릭터, 웹툰 썸네일: 헬로우봇, 타이트사주, 청월당) ④ **전문가 도구형**(원색 오행 블록, 빽빽한 표: 천을귀인, 원광만세력) ⑤ **AI 대화형**(채팅, 추천 질문 칩: 사주핑, 사주GPT, 포스텔러 만세력 AI 상담).
2. 해외 레퍼런스(Co-Star, The Pattern)는 **모노톤과 세리프 타이포, 짧고 단정한 문장**으로 "읽는 경험"을 만들었습니다. 국내 앱 가운데 이 방향을 사주에 적용한 서비스는 이번 조사에서 찾지 못했습니다(빈자리).
3. 입력 폼에서 꼭 지켜야 할 기본(사실상 업계 표준): **양력 / 음력(평달) / 음력(윤달)** 3택(네이버, 원광), **태어난 시 '모름'**과 **12지시(子時 23:30~01:29 등) 대략 선택**(네이버), **출생지 기반 경도 보정**, **서머타임 자동 보정**(천을귀인, 포스텔러 만세력, 원광).
4. 결과 화면 공통 문법: 상단 입력 요약 → **4주 8글자 표**(시·일·월·년 순서, 일간 강조, 한글+한자, 오행 색 타일) → **오행 분포 차트** → 영역별 풀이 섹션 → **대운 타임라인**. 잘 만든 서비스는 **점수의 근거**("왜 78점?" — 정통사주)와 **용어 해설 바텀시트**(포스텔러 만세력)를 함께 둡니다.
5. 피해야 할 패턴: 불안을 부추겨 결제로 유도하는 화면("조심해야 할 게 이만큼"), 재화·광고·출석 같은 리텐션 장치의 과밀, 실사 AI 인물 사진, 근거 없는 최상급 표현("정확도 200%"), 원색 오행 블록의 시각 피로, 긴 AI 응답을 구조 없이 쏟아내는 화면.
6. **권장 방향: "먹과 여백(墨·餘白)" — 모던 동양 미니멀.** UI는 한지색 배경과 먹색 텍스트만으로 구성하고, **색은 오행 데이터에만 씁니다**(색 = 의미). 헤드라인은 명조(Noto Serif KR / 나눔명조), 본문은 Pretendard를 씁니다. 하단 탭은 `오늘 · 내 사주 · 궁합 · 물어보기 · 마이`(기능팀 확정 필요)를 권장합니다.

## 3. 서비스별 상세 분석

> 각 서비스는 **비주얼 / 정보구조(IA) / 핵심 플로우 / 입력 폼 / 결과 화면 / 공유·로딩 / 장점·단점** 순서로 정리했습니다. 확인하지 못한 항목은 "미확인"으로 적었습니다.

### 3.1 점신 (테크랩스)

**비주얼** [확인]
- 마케팅 첫 화면: 블랙 배경, 붓글씨 로고 '점신'과 붉은 낙관, **3D 글로시 오브젝트**(네잎클로버, 별 코인, 과녁), 라임(네온 연두) 강조 텍스트, 월계관 배지("믿을 수 있는 대한민국 사주 앱 1위").
- 앱 내부: **상단 바는 블랙**(날씨 32°C, 재화 '복주머니' 잔액, 검색, 프로필), 본문은 화이트 카드. 마케팅 헤드라인의 강조색은 선명한 블루(대략 #2F6BFF [추정]).
- 동양풍과 모던 중에서는 **모던 쪽**이고, 동양 요소는 로고(붓글씨·낙관) 정도만 남아 있습니다.

**정보구조** [확인]
- 최상위 섹션 이름: `보고서`, `혜택`, `상담`.
- 보고서 안의 서브탭: `운세 / 인맥 / 행운`. 상단 우측에는 **사주정보 프로필 전환**("사주정보 김점신 [변경]")이 있습니다.
- 바로가기 칩: `만세력 / 심풀이 / 출석체크 / 복주머니`.
- 상담 화면: 카테고리 아이콘(운세·타로·신점·심리상담, 무료고민상담, 3분무료상담, 이용가이드)과 추천 상담사 아바타(온라인 상태 점 표시).

**결과 화면** [확인]
- 오늘의 운세: 그제·어제·**오늘**·내일·모레 5일 **라인 그래프** 아래에 큰 숫자 점수("100")와 한 문장 요약("무거운 짐들은 내려 놓아야 하는 하루 입니다.").
- 행운 탭: 요일 선택 + "행운의 야구/골프/코디/음식" 리스트(사진 썸네일 + 해시태그).
- App Store 설명에 따르면 '운세 보고서' 한 화면에서 오늘의 운세, 시간대별 흐름, 바이오리듬, 애정·금전·건강운을 함께 보여 줍니다 [인용].

**유료·광고 유도**
- 브런치 UX 분석은 점신을 '진단형'으로 봅니다. 수치화된 차트로 권위를 세우고, **'결핍의 노출'**(조심할 요소를 짚기)로 1:1 유료 상담까지 연결한다는 분석입니다 [인용: brunch @uibowl/403].
- '행운패스'를 구매하면 전면 광고 없이 이용할 수 있다고 안내합니다. 즉 무료 사용자에게는 전면 광고가 노출됩니다 [인용: App Store].

**사용자 반응** [인용: App Store 리뷰]
- "하루 운세 점수가 낮은 날에는 불안감을 준다"며 점수 대신 다른 표시를 제안한 리뷰가 있습니다(2018).
- 사주 화면의 오행 색상(木 녹색, 水 짙은 파랑)을 바꿔 달라는 요청이 있습니다(2020).
- 메뉴명 '사주정보 변경하기'와 '내 정보 변경하기'가 헷갈린다는 리뷰가 있습니다(2017).

**장점**: 점수와 그래프로 즉시 이해, 프로필 전환으로 가족·지인 사주 관리, 출석·재화 장치로 높은 재방문.
**단점**: 기능과 재화가 너무 많아 산만함, 낮은 점수가 주는 불안, 광고 부담, 메뉴 용어 혼동.

### 3.2 포스텔러 (운칠기삼) — 운세 앱

**비주얼** [확인]
- 2026 시즌 마케팅: **수묵화**(먹 번짐, 소나무, 말), 붉은 해, 붓글씨풍 헤드라인("2026년 신년운세"), 한지 질감. 수상 화면에는 금색 트로피와 골드 텍스트를 씁니다.
- 앱 홈: 화이트 바탕에 상단 검은 원형 로고, 검색·알림 아이콘. **가로 스크롤 카테고리 탭**(`추천 / 사주 / 타로 / 궁합 / 별자리 / 손금 / …`).
- 콘텐츠 썸네일은 **웹툰·포스터풍**으로, 상품마다 일러스트 스타일이 다릅니다. 파란 곰 캐릭터가 군데군데 등장합니다.
- 2018년 기사에 따르면 서비스를 "친한 친구"처럼 설계했고, '현모양처' 같은 성별 고정관념 표현을 쓰지 않습니다 [인용: 한경비즈니스]. 리뷰에서는 "캐릭터가 귀엽다"는 평가가 반복됩니다 [인용].

**정보구조·홈** [확인]
- 홈 상단 히어로 배너 캐러셀("2026 병오년 정통사주 신년운세") → **"실시간 인기 운세" 랭킹 리스트** → 피드 섹션 반복.
- 피드 섹션 공식: 작은 키커("MZ들의 마음을 사로잡은") + 굵은 제목("취향 저격! 재미 가득 무료운세") + 가로 썸네일 레일.
- 하단 탭은 '홈', '프리미엄', '더보기' 등으로 보이나 글자가 작아 일부만 판독했습니다 [추정].

**결과 화면** [확인]
- "나의 오행과 십성": **도넛 차트**(중앙 라벨 '중화신강') + 범례 칩(火 관성 18.2%, 土 인성 4.5%, 金 비겁 50.0%, 水 식상 27.3%).
- **오각형 레이더 차트**: 각 꼭짓점에 원 안의 오행 한자 라벨과 % 표시.
- 설명 문장: "이포스님은 쇠의 기운이 발달한 사람입니다."
- "나의 대운 주기": 10세부터 10년 단위 가로 표.

**용어 해설** [확인]

**보관함** [확인]

**AI 상담** [확인]

**리뷰** [인용]: "디자인 깔끔하고 귀여워서 좋음", "편리한 시스템(그래프 기반)", "맞춤형 풀이 열 때 광고가 너무 깁니다".

**정보구조** [확인] — **시간축 타임라인 IA**가 핵심입니다.

```
허영란님의 운의 흐름
 ┌ 7월 23일 운의 흐름   78점   (ⓘ 왜 78점?)
 │   오늘 간지: 무술 / 내 일간 기준: 천간 식신·지지 식신
 ○ 주간   7.20~7.26 흐름  [상승↗]
 ○ 월별·올해  [7월 운세] [2026 운세]
 ○ 내년   2027년 정미년 운세   [추천]
 ○ 대운   나의 10년 대운 흐름  [신규]
 └ 평생   허영란님의 평생 흐름
정통사주 바로보기: 사주 분석 / 내재물운 / 내애정운 / 건강자녀 / 내직업운 …
```

- **"왜 78점?"** 링크로 점수의 근거를 설명합니다. 점수형 UI가 주는 불안과 불신을 줄이는 좋은 장치입니다.
- 기능 [인용: App Store]: 200% 이상 큰 글자 지원, 사주표 상세(대운·세운·합·충·12운성·12신살), 간지달력, "회원가입 없음 / 서버 저장 없음".

**장점**: 오늘 → 평생으로 이어지는 시간축이 직관적, 점수 근거 제공, 접근성(큰 글자) 배려.
**단점**: 블루 일색이라 감성이 약함, 아이콘 일러스트가 다소 구식이라는 인상 [의견].

### 3.11 사주GPT (스타지오소프트) — AI 사주

**비주얼** [확인]
- 퍼플 브랜드 워드마크("사주 GPT"), 화이트 바탕, **2열 카드 그리드 메뉴**마다 우상단에 **포인트 가격 배지**(FREE, 50P, 70P, 130P …)가 붙습니다.
- 카드 부제에 **톤 경고 라벨**이 있습니다: "반말, 막말 주의", "장문주의".
- 피드 중간에 **'AD' 표기 인피드 광고 카드**가 들어갑니다.
- **AI 캐릭터 상담사 50명 이상**: 실사풍 AI 생성 인물 카드 + 성격 키워드("활기찬, 힙한, 따뜻한…") + 해시태그(#무당 #의사 #피부과). 캐릭터마다 전문 분야(법률, 의학, 패션 등)가 있습니다 [인용: 청소년의회 기사].
- 메뉴명에 모델명이 그대로 노출됩니다: "사주 분석기 PRO 클로드 — 소넷 모델 프리미엄 분석" [확인].
- 웹은 회원가입 없이 시작할 수 있고, **인앱 브라우저 감지 안내**("인앱 브라우저가 감지되었습니다 … 링크 복사하기 / 이대로 써보기")가 있습니다 [확인: HTML].

**리뷰** [인용]: "AI가 요청을 잘 이해하지 못하는 경우가 많아 추천질문만 쓰는 편이 낫다", "대화가 어느정도 가능하며 높은 수준의 풀이".

**장점**: 페르소나 선택이 곧 톤 선택, 가격을 카드에 투명하게 표시, 인앱 브라우저 대응.
**단점**: 메뉴 과다, 기술 용어(모델명) 노출, 실사 AI 인물로 인한 신뢰·불쾌감 리스크, 광고와 유료 메뉴가 같은 그리드에 섞임.

### 3.12 사주핑 — AI 사주 친구

**비주얼** [확인]
- **화이트 미니멀**에 **블랙 말풍선**(사용자 질문), 무지개 그라데이션의 말랑한 **블롭 캐릭터**.
- 홈: "나를 기억하는 사주 친구 / 사주핑" 아래로 **추천 질문 칩**이 흩어져 있습니다("오늘의 운세를 알려줘", "언제 재물은 들어와?", "아이가 갖기 좋은 타이밍을 알려줘", "창업하기 좋은 시기는 언제일까?").
- 궁합: "나와 궁합 볼 사람을 골라주세요." 아래에 지인 리스트가 있고, 각 지인에 **일주동물 태그**("붉은 쥐", "검은 호랑이", "푸른 토끼")와 동물 아바타가 붙습니다. 하단에는 블랙 CTA를 둡니다.
- 답변 화면: 장문 텍스트 + 이모지 섹션 헤더("🕯️ 지금 연락하고 싶은 마음의 근원"), 핵심어 굵게 표시. 입력창 placeholder는 **"어떤 고민이든 물어보세요"**.
- 기능 [인용: App Store]: 답변마다 **'기본 풀이 / 깊은 풀이'** 선택, 답변 끝 후속 질문 제안, 보관함 검색, 운세 캘린더(날짜별 행운색 점), 위젯 테마, 다크 모드, 글자 크기, 앱 잠금, 출석 룰렛, 재화 '핑'.

**장점**: 질문 중심 홈이 진입을 쉽게 함, 대화 맥락 기억(관계형 UX), 미니멀한 톤.
**단점**: 긴 응답이 구조 없이 이어져 훑어보기 어려움 [추정], "최근 답변이 겉핥기식"이라는 리뷰 [인용].

### 3.15 Co-Star (해외 · 미니멀 레퍼런스)

**비주얼** [확인: App Store 스크린샷]
- **오프화이트·라이트 그레이 모노톤**, 얇은 선 그리드 배경, **흑백 판화·조각풍 오브젝트 콜라주**(손, 올빼미, 돌).
- 타이포: **세리프 디스플레이**("Blame the stars", "Understand why you do what you do.") + **모노스페이스 라벨**("CO — STAR", "Do / Don't", "LOVE & PLEASURE").
- **하단 내비게이션을 텍스트로만 구성**: `HOME · FRIENDS · VOID · SHOP · YOU`.
- 홈: "Good afternoon, Hina. It's 55° and sunny. **Today at a glance:** / You're not sad, just bored." 그리고 **Do / Don't 3개씩**("Do: Antiques, Budgeting, Dental care / Don't: Stay home, Deflect praise, Spicy foods").
- 궁합: 항목별 ☺ / 😐 / ☹ 흑백 바 + "Virgo — Pisces >" 형태의 리스트.

**디자인 비평** [인용: Pratt IXD 2022·2024]
- 모노톤이 다른 점성술 앱과의 차별점이고, "저널을 넘기는 듯한" 경험을 줍니다.
- 반면 **글자가 평균보다 작고**(특히 하단 메뉴), 신호(signifier)가 약하며('DETAILS', 얇은 화살표), 온보딩에 **단계 표시와 뒤로 가기가 없고**, 공유 버튼 위치가 화면마다 다르다는 문제를 지적합니다.
- VOID(질문 기능)의 은하수 로딩 애니메이션이 유일하게 화려한 시각 피드백입니다.

**시사점**: 우리 서비스의 "읽는 경험"과 "절제된 톤"의 레퍼런스로 삼되, **글자 크기·버튼 신호·단계 표시**는 Co-Star와 반대로 명확하게 가야 합니다.

### 3.16 The Pattern (해외)

[확인: App Store 스크린샷, 인용: screensdesign.com]
- 마케팅: 다크 차콜 + 화이트 산세리프, **잉크 원상(ensō) 로고**.
- 앱: 라이트 카드, **블루 볼드 타이틀**("Ambition & Success or Feelings of Inadequacy"), 틸 라벨, 트랜짓 카드의 **원형 진행 표시("9 months left")**. 대운·세운의 '남은 기간' 표현에 그대로 응용할 수 있습니다.
- 온보딩 [인용]: 환영 → 가입 옵션 → 이메일 인증 → 이름·생년월일·성별 → **출생지 검색 + 지도** → **입력 내용 확인 화면(동의 체크박스 2개, "View My Pattern")** → 알림 권한 → 페이월.
- 하단 탭: Lens / Discover / You [인용]. 커뮤니티 피드("Shared Experiences")도 있습니다.

**시사점**: **'입력 확인(Review Details)' 단계**가 생년월일시 오입력을 줄여 줍니다. 결과를 다시 계산하는 비용과 CS 문의를 줄이는 효과가 있습니다.

### 3.17 Sanctuary (해외)

[확인: App Store 스크린샷, 웹 메타]
- **라벤더 → 블루 그라데이션**, 반짝임(✦) 장식, 앱은 **딥네이비 다크 + 달 사진**, 보라 칩. 웹 theme-color는 #F6F2FA입니다.
- "Good Evening" 인사 + 태양·달·상승궁 요약, Today/Tomorrow/Weekly/Monthly 탭, Explore 타일 그리드, 리더(상담사) 마켓플레이스(사진, 분당 가격, 평점).
- 카피: "UNLOCK YOUR FUTURE", "Get Clarity in 5 Minutes".

**시사점**: 퍼플·라벤더는 글로벌 점성술 앱의 **클리셰 컬러**입니다(국내 사주GPT도 퍼플). 차별화하려면 피하는 편이 낫습니다.

## 5. 공통 패턴 (따라 할 것)

1. **입력 → 결과까지 1분 이내**: 회원가입 없이 결과부터 보여 주는 구조(신한라이프, 사주GPT, 타이트사주, 정통사주의 "회원가입 없음"). 저장·공유 시점에 가입을 유도합니다.
2. **양력 / 음력(평) / 음력(윤) 3택 + 시간 '모름' + 12지시 대략 선택**(네이버, 원광).
3. **보정 내역 투명 표시**: "지역시 16:06 (보정: 지역 −23분)"(포스텔러 만세력).
4. **4주 8글자 표의 표준 문법**: 시·일·월·년 열, 일간 강조 '(나)', 한글+한자+오행+음양 표기, 오행 색 타일.
5. **용어는 탭하면 바텀시트로 해설**(포스텔러 만세력).
6. **점수에는 근거를**: "왜 78점?"(정통사주), 또는 점수 대신 행동 라벨 '적극활용/활용/주의/경계'(신한 SOL).
7. **시간축 IA**: 오늘 → 주간 → 월 → 올해 → 대운(10년) → 평생(정통사주), 남은 기간 원형 표시(The Pattern).
8. **질문형 진입**: 추천 질문 칩(사주핑), 질문형 상품 부제("우리 둘, 진짜 잘 맞는 걸까?" — 햄별사주).
9. **프로필 전환·보관함**: 가족·지인 사주 저장, 즐겨찾기, 태그(포스텔러 만세력, 점신).
10. **공유를 위한 별도 카드 포맷**: 운세 ID 카드(헬로우봇). 결과 화면 캡처와 공유 카드를 분리해 디자인합니다.
11. **일주 캐릭터·별칭으로 정체성 부여**: "정묘(붉은 토끼)"(포스텔러 만세력), "붉은 쥐"(사주핑). 공유와 대화의 소재가 됩니다.
12. **AI 대화는 구조화된 카드와 함께**: 채팅 안에 명식 카드·8글자 표 카드를 넣기(포스텔러 만세력, 사주핑).

### 7.1 포지셔닝

- **한 문장**: "맞히는 사주가 아니라, **읽히는** 사주" — 정확한 만세력 계산 위에 쉽고 단정한 해석을 얹고, 조용하고 품위 있는 화면에 담습니다.

### 7.4 오행 5색

오행마다 **3단 토큰**을 둡니다. `solid`는 차트·아이콘·막대처럼 텍스트가 아닌 그래픽에 쓰고(배경 대비 3:1 이상), `soft`는 8글자 타일 배경, `ink`는 soft 위의 글자나 오행 이름 텍스트에 씁니다.

| 오행 | 의미 색 | Light `solid` | Light `soft` | Light `ink` | Dark `solid` | Dark `soft` | Dark `ink` |
|---|---|---|---|---|---|---|---|
| 木 목 | 청록 (푸른 잎) | **#2E7D67** | #E2F1EB | #1D5444 | **#5BB89A** | #1C2F28 | #A9E0CC |
| 火 화 | 주홍 (불꽃) | **#C94A33** | #FBE6E0 | #8E2E1F | **#EE7A62** | #3A201A | #F8C2B5 |
| 土 토 | 황토 (흙) | **#A87521** | #F6EDD7 | #6E4E14 | **#DDB060** | #352A15 | #F1D9A6 |
| 金 금 | 백금·은회 (쇠) | **#737982** | #ECEDEF | #41464D | **#AEB4BD** | #2A2C30 | #DDE0E4 |
| 水 수 | 쪽빛 남흑 (깊은 물) | **#2D3B5C** | #E2E6F0 | #1E2840 | **#7F98CF** | #1C2335 | #C5D2EE |

대비 검증 (계산값)
- Light `solid` vs canvas(#F7F3EC): 木 4.47 / 火 4.21 / 土 3.63 / 金 3.97 / 水 10.04 → 모두 비텍스트 3:1 이상 ✅
- Light `ink` vs `soft`: 7.49 / 6.83 / 6.52 / 8.12 / 11.73 → 텍스트 AA 이상 ✅
- Dark `solid` vs canvas(#14130F): 7.76 / 6.72 / 9.25 / 8.91 / 6.46 ✅, Dark `ink` vs `soft`: 9.5~10.6 ✅

**규칙**
- 오행은 **색 + 한자 + 한글 라벨**으로 함께 표기합니다. 색만으로 구분하지 않습니다(색각 이상 대응).
- 음양은 색이 아니라 **기호(＋/－) 또는 채움·외곽선 스타일**로 구분합니다. 예: 양간은 채운 타일, 음간은 soft 배경 + 1px solid 테두리.
- 오행 색을 버튼, 배너 같은 UI 크롬에 쓰지 않습니다("색은 오행의 것").

| 헤드라인·한자 | **Noto Serif KR** (1순위) 또는 **나눔명조** | 둘 다 SIL OFL, Google Fonts 제공 | 8글자 표의 한자(甲乙丙丁…子丑寅卯…)와 木火土金水를 명조로 표기. Noto Serif KR은 200~900 굵기 지원 |
| 숫자 | Pretendard + `font-variant-numeric: tabular-nums` | — | 점수, 날짜, 대운 나이 정렬 |
| (선택) 감성 포인트 | 고운바탕 (Gowun Batang) | SIL OFL, Google Fonts | 공유 카드 인용구 등 제한적으로 |

- **마루부리**(네이버)는 라이선스 원문을 확인하지 못해 후보에서 뺐습니다(재확인 후 검토 가능).
- **모바일 타입 스케일** (기준 16px)

| 토큰 | 크기/행간 | 굵기 | 폰트 |
|---|---|---|---|
| `display` | 32 / 40 | 600 | Noto Serif KR |
| `title.lg` | 26 / 34 | 600 | Noto Serif KR |
| `title.md` | 22 / 30 | 600 | Pretendard |
| `title.sm` | 18 / 26 | 600 | Pretendard |
| `body.lg` | 17 / 28 | 400 | Pretendard (풀이 장문) |
| `body.md` | 16 / 26 | 400 | Pretendard (기본) |
| `body.sm` | 14 / 22 | 400 | Pretendard |

- 한국어 장문 가독성을 위해 풀이 본문은 **행간 1.6~1.7**, 한 줄 최대 **약 34자**(모바일 기본폭 기준), `word-break: keep-all`을 씁니다.
- 자간: Pretendard 본문 `-0.01em`, 제목 `-0.02em`. 명조는 `0`.
- 웹폰트 로딩: Pretendard는 dynamic subset, Noto Serif KR은 **간지·오행 한자 + 헤드라인용 글자만 서브셋**(Google Fonts `text=` 파라미터 또는 자체 서브셋)으로 받고, `font-display: swap`을 씁니다. Capacitor 앱에서는 폰트 파일을 앱 번들에 넣습니다(OFL은 임베딩 허용).

### 7.6 형태·간격·모션 토큰 (요약)

| 분류 | 토큰 |
|---|---|
| 간격 (4pt 그리드) | `space.1`=4, `2`=8, `3`=12, `4`=16, `5`=20, `6`=24, `8`=32, `10`=40, `12`=48 |
| 화면 좌우 여백 | 20px (작은 기기 360px에서는 16px) |
| 모서리 | `radius.sm`=8 (칩), `md`=12 (입력·타일), `lg`=16 (카드), `xl`=24 (바텀시트 상단), `full` (알약 버튼) |
| 그림자 | 거의 쓰지 않음. 카드는 1px `border.default`로 구분하고, 시트에만 `0 -8px 24px rgba(31,29,26,.08)` |

| 아이콘 | 1.5px 라인 아이콘, 24px 그리드 (예: Lucide/Phosphor 계열, 라이선스 확인 후 선택) |

### 7.7 화면 목록 (IA)

> 기능 범위는 기능팀 확정 전이므로 **MVP / 다음 단계**로 나눠 제안합니다.

```
[웹 진입]
 W0  랜딩 (비로그인, SEO)                     MVP
 W1  사주 입력 (3단계 또는 단일 폼)           MVP
 W2  입력 확인                                MVP
 W3  계산·생성 로딩                           MVP
 W4  결과 (8글자·오행·섹션·잠금)              MVP
 W5  결제 바텀시트 → 결제 완료/실패           MVP
 W6  공유 카드 미리보기                       MVP

[하단 탭 — 로그인 또는 로컬 프로필 생성 후]
 T1  오늘      : 오늘의 운세, 주간 흐름, 오늘의 한 줄       MVP
 T2  내 사주   : 내 명식(8글자), 섹션별 풀이, 대운 타임라인  MVP
 T3  궁합      : 사람 선택 → 궁합 결과                     다음 단계
 T4  물어보기  : AI 대화(내 명식 맥락), 추천 질문          다음 단계(LLM 범위 확정 후)
 T5  마이      : 저장한 사주(보관함), 결제 내역, 알림 설정, 테마, 글자 크기, 약관·면책  MVP

[공통]
 C1  사람 추가/편집 (= W1 재사용)
 C2  용어 해설 바텀시트
 C3  빈 상태 / 오류 / 오프라인
 C4  알림 권한 프리프롬프트 (OS 권한 요청 전 설명 화면)
```

**하단 탭 권장안**: `오늘 · 내 사주 · 궁합 · 물어보기 · 마이` (5개 — iOS 탭바 권장 최대치)
- MVP에서 궁합·AI가 빠지면 `오늘 · 내 사주 · 마이` 3탭으로 시작하고, 탭 추가는 아이콘 위치 변경 없이 가운데에 끼우는 구조로 설계합니다.
- 탭 라벨은 **아이콘 + 한글 텍스트**로 하고 최소 11pt를 지킵니다(Co-Star식 텍스트 전용 탭은 신호가 약하다는 비평이 있었음).

### 7.8 핵심 사용자 플로우

```
(검색/공유 링크) → W0 랜딩 ─[내 사주 보기]→ W1 입력 → W2 확인 → W3 로딩(2~4초 + 스트리밍)
   → W4 결과(무료: 8글자·오행·총평·각 섹션 첫 문단)
        ├─[공유]→ W6 공유 카드 → 카카오톡/링크/이미지 저장
        ├─[저장]→ (가입 또는 로컬 저장) → T2 내 사주
        └─[전체 풀이 열기]→ W5 결제 시트 → 완료 → W4 (잠금 해제 + 스크롤 위치 유지)
재방문: 푸시(오늘의 운세) → T1 오늘 → T2/T3/T4
```

원칙
- **결과를 먼저, 가입은 나중에**: 저장·재방문·결제 시점에 가입을 요청합니다.
- 결제 후에는 **원래 읽던 섹션 위치로 복귀**합니다(맥락 유지).

### 7.10 입력 폼 상세 사양

| 필드 | 컨트롤 | 규칙·검증 | 비고 |
|---|---|---|---|
| 이름 | text, `maxlength=12` | 선택. 비우면 "나"로 표기 | 실명 강요 금지 |
| 달력 | 세그먼트 `양력 / 음력` + 체크박스 `윤달이에요` | 윤달 체크는 음력에서만 노출. 해당 연·월에 윤달이 없으면 오류 표시 | 네이버식 3택(양력/음력(평)/음력(윤))도 대안. 사용성 테스트로 결정 |
| 생년월일 | `inputmode="numeric"` 8자리 + 자동 포맷 `YYYY.MM.DD`, 보조로 네이티브 date picker 버튼 | 존재하지 않는 날짜(2/30), 미래 날짜, 지원 범위 밖 연도 차단 | **휠 피커만 쓰지 않기**: 1990년대 연도까지 스크롤이 길어짐. 숫자 입력이 가장 빠름 [추정, 테스트 권장] |
| 태어난 시간 | `HH:MM` 숫자 입력(24시간제) / **12지시 시간대 시트** / **모름** 칩 | 00:00~23:59. '모름'이면 시주를 `?`로 처리하고 안내 | 시간대 경계(예: 23:30)와 야자시 처리는 **계산팀 정책에 따름** |
| 성별 | 세그먼트 `여성 / 남성` | 필수. ⓘ에 "대운 방향(순행·역행) 계산에 필요" 설명 | 그 밖의 성별 표기 요구 대응은 기획 논의 필요 |
| 출생지 | 검색 시트(시·군 단위), 기본값 '서울', '해외' 옵션 | 경도 보정 값은 확인 화면에 표시 | 해외 출생은 시간대·서머타임 처리 별도 정책 필요 |
| 고급 설정 | 토글 3개: 경도 보정 / 서머타임 보정 / 야자시 적용 | 기본값은 계산팀 권고안 | 한국은 과거 서머타임 시행 연도와 표준시 변경(1954~1961년 UTC+8:30 사용) 이력이 있어 보정 필요 [추정 — 계산팀 검증 필요] |

- **스텝형 vs 단일 폼**: Co-Star 비평은 스텝형에 진행 표시와 뒤로 가기가 없다는 점을 지적했습니다. 스텝형을 택한다면 ① 진행 바 ② 뒤로 가기 ③ 마지막 '입력 확인' 화면, 세 가지를 반드시 넣습니다.
- **오류 표시 위치**: 필드 바로 아래, 아이콘 + 문장. 제출 시점이 아니라 **포커스가 빠질 때(onBlur)** 검증합니다.
- **입력값 기억**: 로컬에 저장하고 "다음에도 이 정보로 볼게요" 체크박스를 둡니다(네이버 '생년월일 기억하기' 패턴). 개인정보 처리 정책과 연동합니다.

### 7.11 결과 화면 상세 사양

1. **헤더 영역**: 일주 별칭 + 한 줄 총평(명조) + 입력 요약(탭하면 수정).
   - 일주 별칭은 천간 오행 색(甲乙 푸른, 丙丁 붉은, 戊己 노란, 庚辛 흰, 壬癸 검은)과 지지 띠동물을 조합하는 관행을 따릅니다. 예: 壬寅 → '검은 호랑이', 丁卯 → '붉은 토끼'(포스텔러 만세력·사주핑 사례).
2. **8글자 표**
   - 열 순서: **시 · 일 · 월 · 년**(국내 앱 관행). 일간 열은 굵은 테두리와 '나' 라벨로 강조합니다.
   - 타일 내용: 한자(대) + 한글 + 오행(한자) + 음양 기호. 탭하면 해당 글자 설명 바텀시트를 엽니다.
   - 기본 모드는 십성까지만 보여 줍니다. **전문가 보기** 토글로 12운성·12신살·지장간·합충을 펼칩니다.
   - 375pt에서 타일 최소 64×72pt, 한자 28~36px.
3. **오행 분포**: 가로 막대 5개 + 개수(또는 %) + 상태 라벨(발달/적정/부족/없음). 판정 기준(예: 20%·30%·10%)은 ⓘ 시트에 투명하게 공개합니다(포스텔러 만세력 사례).
4. **섹션 구성(순서)**: 총평 → 성격 → 재물운 → 연애운 → 직업운 → 건강운 → 대운 흐름 → 올해의 운세.
   - 각 섹션은 `기능 라벨 + 감성 제목 + 3줄 요약 + 본문 + '이렇게 해 보세요'` 구조입니다.
   - 섹션 칩 내비는 스크롤 시 상단에 고정됩니다.
5. **잠금 처리**
   - 각 섹션의 **첫 문단은 실제 내용을 공개**하고, 그 아래를 60px 페이드로 마감합니다.
   - 잠금 카드에 **유료 부분의 목차**(소제목 3개)를 공개합니다.
   - 블러는 **이미지형 요소(차트 등)에만 제한적으로** 쓰고, 텍스트 블러는 쓰지 않습니다(읽을 수 없는 가짜 문장은 기만으로 느껴짐).
   - 결제 후 잠금 해제 애니메이션은 0.3초 페이드로 하고, 스크롤 위치를 유지합니다.
6. **대운 타임라인**: 10년 단위 가로 스크롤, 현재 대운 강조 + '남은 기간' 원형 표시, 각 대운을 탭하면 요약 시트를 엽니다.
7. **면책 문구**: 결과 하단과 건강운 섹션 안에 고정 노출합니다(`04` 문서 문구).

### 7.12 로딩 연출

- **두 단계 로딩**
  - 만세력 계산(결정적 계산)은 즉시 끝나므로 **8글자 표와 오행 차트를 먼저 렌더링**합니다.
  - LLM 풀이는 **섹션 단위로 스트리밍**하고, 아직 채워지지 않은 섹션은 스켈레톤으로 둡니다.
  - 체감 대기 시간을 줄이고, 결제 전 핵심 가치(표·차트)를 바로 보여 줍니다.
- 전용 로딩 화면은 **최소 1.5초, 최대 4초**만 보여 줍니다. 단계 문구 5개를 순환시키되, 실제 진행보다 느리게 보여 주는 '가짜 대기'는 만들지 않습니다.
- 애니메이션: 먹이 번지는 원 → 오행 5색 점이 차례로 맺힘(Lottie 또는 CSS). `prefers-reduced-motion`이면 정적 아이콘 + 문구만 보여 줍니다.
- 8초를 넘기면 "조금만 더 기다려 주세요" 보조 문구를 보여 주고, 20초를 넘기면 재시도와 '알림으로 받기' 선택지를 제시합니다[추정 기준값, 실측 후 조정].

### 7.14 모바일 퍼스트 & 앱 포팅(Capacitor) UX 원칙

현재 모노레포 설명에는 "web(프론트, Capacitor 앱 포팅)"이라고 되어 있어 이를 전제로 작성했습니다.

1. **Safe area**
   - `<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">`를 지정합니다.
   - 헤더와 하단 탭에 `padding-top: env(safe-area-inset-top)`, `padding-bottom: env(safe-area-inset-bottom)`을 적용합니다.
   - 하단 고정 CTA는 홈 인디케이터 위에 둡니다.
   - 가로 모드에서는 `inset-left/right`도 반영합니다.
2. **뷰포트 높이**: `100vh` 대신 `100dvh`/`100svh`를 씁니다. 키보드가 올라오면 `visualViewport`(웹)나 Capacitor Keyboard 플러그인으로 CTA 위치를 보정합니다.
3. **터치 영역**: 최소 **44×44pt(iOS HIG) / 48×48dp(Material)** [인용: 2차 자료]. 칩·세그먼트 높이는 40pt 이상, 인접 터치 영역 사이 간격은 8pt 이상.
4. **입력 최적화**
   - 숫자 필드는 `inputmode="numeric"`과 `pattern="[0-9]*"`를 씁니다.
   - 입력 폰트는 **16px 이상**으로 둡니다(iOS 사파리 자동 확대 방지).
   - 자동 포맷 중에도 커서 위치를 유지합니다.
5. **내비게이션**: 하단 탭 + 스택 내비게이션. 안드로이드 하드웨어 뒤로 가기(Capacitor App `backButton`)와 iOS 스와이프 백을 둘 다 고려해, **모달·시트는 뒤로 가기로 닫히게** 합니다.
6. **바텀시트**: 선택지·용어 해설·결제는 바텀시트로 처리하고, 높이는 최대 90%로 둡니다. 드래그로 닫기 + 명시적 닫기 버튼을 함께 둡니다.
7. **상태바·테마**: 라이트·다크 전환 시 Capacitor StatusBar 스타일과 `theme-color` 메타를 동기화합니다(#F7F3EC / #14130F).
8. **햅틱**: 결과 표 등장, 결제 완료 같은 의미 있는 순간에만 가볍게 씁니다(Capacitor Haptics). 웹에서는 생략합니다.
9. **인앱 브라우저 대응**: 카카오톡·인스타 인앱 브라우저에서는 결제·로그인이 막힐 수 있으므로 감지 후 "기본 브라우저로 열기" 안내를 띄웁니다(사주GPT 사례).
10. **오프라인·재방문**: 계산된 명식과 마지막 결과는 로컬에 캐시해 오프라인에서도 열람할 수 있게 합니다. 네트워크 오류 화면에는 재시도 버튼을 둡니다.
11. **글자 크기 확대**: 시스템 글꼴 크기(Dynamic Type) 200%에서도 레이아웃이 깨지지 않게 하고, 앱 내 '글자 크기' 설정도 둡니다(정통사주, 사주핑 사례). 8글자 표는 확대 시 2행 래핑을 허용합니다.
12. **App Store 심사 리스크**: Apple 가이드라인 4.3(b)는 'fortune telling'을 포화 카테고리로 명시하고, "의미 있게 다르거나 개선된 경험"이 아니면 신규 제출을 받지 않는다고 적고 있습니다. 4.2는 '웹사이트를 재포장한 수준'의 앱을 거절합니다 [인용: Apple App Review Guidelines].
    - 앱 포팅 시 **위젯(오늘의 한 줄), 로컬 알림, 공유 시트, 오프라인 보관함, 햅틱** 같은 네이티브 가치를 갖추고, 차별화 포인트(디자인·해석 방식)를 심사 노트에 명시할 것을 권장합니다.
13. **푸시 권한**: OS 권한 요청 전에 **프리프롬프트 화면**(무엇을, 언제, 얼마나 자주 보내는지)을 먼저 보여 줍니다. 첫 결과를 본 뒤에 요청합니다(온보딩 첫 화면에서 요청하지 않음).
14. **성능**: LCP 이미지(랜딩 샘플 표)는 SVG/CSS로 구현하고, 폰트는 서브셋으로 받습니다. 결과 페이지 JS는 지연 로드합니다.
