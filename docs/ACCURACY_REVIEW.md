# 명리학 설명 정확성 점검 — 2026-10-16

문체 기준 개정(docs/PLAIN_KOREAN.md)과 함께 서비스 전체 문구를 점검했다. 여기에는 부정확하거나 오해를 줄 수 있어서 고친 설명을 모았다. 문체만 바꾼 문장은 넣지 않았다.

## 1. 핵심 개념 — 여러 화면에 걸친 문제

## 2. 무료 풀이·오늘·신년·궁합

- 병화 건강에 '눈'을 넣었다. 오관상 눈은 목에 속하므로, 화는 심장·소장·혈액순환, 토는 비장·위장으로 고쳤다.
- 편재의 쉬운 이름 '활동·큰돈'을 '사업·재물'로 바꿨다. '큰돈'은 과장이고, 편재는 유동 재물과 사업을 뜻한다.
- 신년운세가 그해의 천간과 지지의 십성이 같을 때 10년 대운 문구를 1년 운세에 썼다. 이를 삭제했다.
- "세운의 천간 상관이 들어와요"를 "세운의 천간 정은 일간에게 상관에 해당"으로 고쳤다. 십성은 일간 기준이다.
- 궁합의 '둘 다 지치기 쉬운 달'이 한 사람의 점수만 낮은 달을 골랐다. 두 사람 모두 낮은 달을 고르게 고쳤다.
- 일주 풀이 가운데 일주와 근거 없이 연결된 문장을 삭제했다(기사일주 '이동이 잦은 일', 정해일주 '해외·이동 업무').

## 3. 타로·띠·별자리·택일·상담·꿈(규칙 기반)

- **택일 사리일**: "계절이 바뀌기 전날" → 춘분·하지·추분·동지의 전날. 계절 경계는 사절일(입춘·입하·입추·입동 전날)이다.
- **택일 황도·흑도**: "번갈아 정한다" → 12천신이 날마다 정해진 순서로 돈다. 황도 6, 흑도 6이며 번갈아 오지 않는다.
- **택일 천덕·월덕**: 천을귀인 설명("도와주는 사람")과 섞여 있었다 → 하늘의 덕·그달의 덕으로, 흉함을 누그러뜨린다.
- **택일 혼인 십성**: 겁재·상관이 배우자성(재성·관성)을 극한다는 점을 밝혔다.
- **띠 년생별 십성**: 연간 기준인 달빛사주 방식이라고 밝혔다(정식 사주는 일간 기준). 눈여겨볼 날의 관계에 형·해·원진도 포함했다.
- **별자리 '홀사인 하우스'**: 태양 별자리 기준인 솔라 하우스로 바로잡았다(홀사인은 상승궁 기준). '생일로 정해지는 별자리'는 태양 별자리로, 생일 달은 솔라 리턴으로 설명했다.
- **타로**
  - 완드 = 목처럼 썼다 → 전통은 완드 = 불, 소드 = 공기다. 메이저는 골든 던의 행성·별자리·원소 대응을 따르고, 동양 이름이 있는 것은 행성뿐이다.
  - 소드 3 정방향 키워드 '치유의 시작'은 역방향 뜻이므로 '실망'으로 고쳤다.
  - 바보 카드의 '절벽 = 위험 확인'을 미지로 내딛는 걸음으로 고쳤다.

## 4. 토정비결(144괘)

- **괘사 오독 수정**: 321(方), 422(兄耶弟耶), 213(損財), 633(骨肉相爭), 721(陰陽和合 — 하늘과 땅 → 음과 양), 841·851(빠진 구절 보완), 853(死生難辨), 862(砲), 761(一人之害), 763(飛龍在天 利見大人), 742·522·662.
- **요약·총평과 열두 달 흐름이 어긋난 곳(약 60괘)**: 계절 표현, '처음엔 고단하다', '가을부터 나아진다' 같은 시기 서술과 방향을 실제 달 흐름에 맞췄다. 달 흐름 값은 바꾸지 않았다.
- **한 괘 안에서 달 문장끼리 모순되던 곳**을 고쳤다: 163, 311, 632, 722, 553, 863.
- **달 이름**: '힘이 붙는 달 / 살피는 달'을 '좋은 달 / 무난한 달 / 조심할 달'로 바꿔 신년운세 등급과 맞췄다.

## 5. 꿈해몽 사전

- **돈 꿈**: 전통 구분을 따른다. 받는 꿈은 근심, 주거나 잃는 꿈은 근심이 사라진다는 뜻이다.
- **잘못 쓴 말과 일화**: '말복'(末伏) 오용을 바로잡았고, 오줌 꿈은 문희 일화로 명시했다.
- **빠져 있던 전통 해석을 보완**: 피 = 재물, 신발 잃는 꿈, 이빨(윗니·아랫니), 반대 꿈(웃는·우는·다투는 꿈), 감옥 = 길몽 등.
- **길흉 표시와 본문이 어긋나던 항목**을 고쳤다: 집 무너지는 꿈, 더러운 화장실, 땀, 비.
- **사용자 결정이 필요한 항목**(길흉 표시는 바꾸지 않음): 천둥(중립 → 길?), 마른 우물(중립 → 흉?), 불 끄는 꿈·해 지는 꿈(중립 → 흉?), 개에게 물리는 꿈(중립 → 흉?).

## 6. 달빛사주 자체 기준 표시

다음 값은 화면이나 리포트에서 '달빛사주 기준' 또는 '서비스 자체 지표'라고 한 번 밝히게 했다.

- 오늘 총운·분야별 점수, 운세 등급
- 궁합 점수
- 신강·신약 점수와 단계 이름
- 오행 개수 집계와 가중 비율
- 용신 계산 방식, 대운 시작 나이 계산
- 택일 등급·점수
- 띠·별자리 기간별 흐름, 타로–오행 대응, 직장형·독립형 구분
